# Security policy

Do not open a public issue containing Eufy credentials, Home Assistant tokens,
captcha or MFA values, session identifiers, device or station serial numbers,
local network addresses, or unredacted logs.

For a suspected vulnerability in the upstream client or server, report it to
the relevant upstream project. For a packaging-specific vulnerability in this
repository, use GitHub's private vulnerability reporting feature if available.

This experimental add-on is provided without warranty. Keep the original
stable add-on installed and test read-only behavior before enabling automatic
boot.
